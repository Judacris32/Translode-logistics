# Photographs

All photographs are in `public/images/` as optimised JPEGs. To replace one, save the new picture
over the old file with the same name. No code change is needed unless the subject moves, in which
case adjust the `position` value (the focal point) where the picture is used.

## Hero pictures

Headers put the headline on the left and darken that side, so the subject of a hero picture
should sit in the right half. Wide pictures, about 2.2 to 1, at 1800 px or wider.
